# Як додати роботу на GitHub

Репозиторій уже створено: https://github.com/LitruzZz/course-monitoring-python-2026
Для поточного завантаження почніть із кроку 5 нижче.

1. Увійдіть у власний GitHub і відкрийте https://github.com/new.
2. Назва, наприклад: `course-monitoring-python-2026`.
   Це один репозиторій для ЛР15–18, не окремий для кожного етапу.
3. Видимість Public або Private оберіть за вимогами викладача.
   Не створюйте додаткові README чи .gitignore: вони вже є в комплекті.
4. Натисніть Create repository.
5. На сторінці порожнього репозиторію натисніть uploading an existing file
   або Add file → Upload files, якщо ця команда доступна.
6. Розпакуйте ZIP лабораторної. Відкрийте папку `course_monitoring`.
   Перетягніть **її вміст**, зокрема папки `config`, `monitoring`,
   `framework_examples`, `docs` та файли `manage.py`, `requirements.txt`,
   `requirements-lock.txt`, `.gitignore`, `README.md`, `profile08.json`.
   Завантажуйте файли й папки, а не ZIP.
7. Підтвердьте додавання файлів. Назва коміту: `ЛР15 — початковий Django-проєкт`.
   Якщо GitHub пропонує Commit changes — натисніть його.
   Якщо пропонує нову гілку — завершіть запропонований GitHub процес додавання.
8. Перевірте, що `manage.py` та `README.md` видно в корені репозиторію.
9. Скопіюйте адресу репозиторію з браузера й додайте її у звіт замість порожнього
   поля. Можна надіслати посилання в чат, щоб отримати оновлений Word-звіт.
10. Якщо репозиторій приватний, надайте викладачу доступ згідно з правилами курсу.

У комплекті ZIP вже виключені середовище, база, кеші й секрети.
Не додавайте їх, якщо запускатимете проєкт перед завантаженням.
Викладачу подають DOCX і ZIP та посилання на GitHub у звіті.
